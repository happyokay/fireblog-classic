# Fireblog Classic

A lightweight WordPress theme for a sparse, text-first weblog.

## Archive Page

Create a WordPress page with the slug `archive`. WordPress will use `page-archive.php` automatically, listing all published posts grouped by month with headings such as `May 2026`.

## Sidebar

Assign a menu to the `Sidebar Menu` location to replace the default links. The author name and sponsor copy can be changed in the Customizer under `Fireblog Options`.
